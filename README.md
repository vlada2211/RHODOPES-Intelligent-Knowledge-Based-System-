# RHODOPES – Intelligent Knowledge-Based System

## Overview

RHODOPES is an intelligent knowledge-based system developed in **SWI-Prolog** as a Bachelor's degree project. The system provides structured information about the Rhodope Mountains and allows users to explore different topics through an interactive menu.

The project demonstrates the application of **knowledge representation, logical inference, rule-based reasoning, and intelligent recommendations**.

## Features

- Interactive menu-based interface
- Information about the relief, climate, water resources, flora, and fauna
- Exploration of geographical features and protected areas
- Information about tourist attractions and destinations
- Cultural heritage and legends
- Search functionality
- Knowledge-based recommendations
- Interactive quizzes
- Logical rules and inference based on stored knowledge

## Knowledge Modules

The system includes the following knowledge domains:

1. Relief
2. Climate
3. Water
4. Flora
5. Fauna
6. Attractions
7. Geography
8. Protected Areas
9. Tourism
10. Culture and Legends

## Technologies

- **Programming Language:** Prolog
- **Prolog Environment:** SWI-Prolog
- **Approach:** Rule-Based Artificial Intelligence
- **Concepts:** Knowledge Representation, Logical Inference, Expert Systems

## System Architecture

The system is based on a knowledge-driven architecture that combines facts and logical rules to provide information, answer queries, and generate recommendations.

The knowledge base contains information about different aspects of the Rhodope Mountains. Logical rules process this information and derive new conclusions based on predefined relationships and conditions.

## Project Statistics

- Over **500 facts**
- More than **60 logical rules**
- 10 knowledge domains
- Interactive menus, quizzes, search, and recommendation functionality
